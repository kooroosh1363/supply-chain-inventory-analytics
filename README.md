# DA-09 — Supply Chain & Inventory Analytics

This repository is being developed as a portfolio-grade operations analytics case study focused on supply-chain performance, inventory health, stockout risk, lead-time analysis, supplier performance, and decision-ready operational insights.

## Data strategy

DA-09 will use real/public operational data with verifiable provenance and documented source constraints. We will only calculate KPIs that are directly supported by the source data; unsupported inventory, cost, supplier, or lead-time fields will not be invented.

## Planned scope

- Real/public supply-chain or logistics data
- Data provenance and data dictionary
- Demand and order-volume analysis
- Inventory-health or stock-risk analysis where supported
- Lead-time and fulfillment analysis where supported
- Supplier/vendor performance where supported
- Shipping/service-level KPIs
- Pareto / ABC-style operational prioritization where valid
- Data-quality and reconciliation checks
- Reproducible Python analytics
- Tests and GitHub Actions CI

> Full development will happen on a dedicated branch before final review and merge.
